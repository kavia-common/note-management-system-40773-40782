# Notes App - Angular (Ocean Professional)

Angular-based notes management UI with CRUD, Ocean Professional theme, and environment mapping from existing `REACT_APP_*` variables.

## Run

- npm install
- npm start
Visit http://localhost:3000

## Build

- npm run build

## Environment Variables

See MIGRATION_NOTES.md for details on mapping from `REACT_APP_*` to Angular environments.

## Features

- Notes list with search and keyboard navigation
- Create, view, edit, delete notes
- API integration via environment.apiBaseUrl or in-memory fallback
- Accessible focus styles and confirmation dialog
- Ocean Professional theme with gradient header and modern styling
